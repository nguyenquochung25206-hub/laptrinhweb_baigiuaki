# Porfolio-Nga — Cyber Ocean

Portfolio cá nhân mẫu bằng HTML, CSS và JavaScript thuần.

## Chạy trên máy
1. Giải nén thư mục.
2. Mở thư mục trong VS Code.
3. Mở `index.html` trực tiếp bằng trình duyệt hoặc dùng tiện ích Live Server.
4. Không cần XAMPP cho phiên bản tĩnh này.

## Thêm ảnh cá nhân
Đặt ảnh vào `assets/images/` và đặt tên `avatar.jpg`. Trang chủ tự hiện khung thay thế nếu chưa có ảnh.

## Thêm CV PDF
Đặt file CV của bạn trong `assets/documents/` nếu sau này muốn liên kết trực tiếp đến PDF. Trang `resume.html` hiện có nút in/lưu PDF từ trình duyệt.

## Trước khi nộp
- Kiểm tra GPA và thang điểm.
- Bổ sung tên trường, email và thông tin liên hệ muốn công khai.
- Chỉ giữ kỹ năng/dự án đúng với thực tế; nội dung có nhãn “mẫu/ý tưởng” cần được chỉnh.
- Biểu mẫu liên hệ chưa gửi email thật; cần dịch vụ biểu mẫu hoặc backend nếu muốn gửi thật.
- Kiểm tra tất cả đường dẫn, menu và hiển thị trên điện thoại.

## Tệp chính
- `index.html`: Trang chủ
- `about.html`, `skills.html`, `projects.html`, `project-detail.html`
- `experience.html`, `education.html`, `blog.html`, `contact.html`, `resume.html`, `404.html`
- `css/`: giao diện và responsive
- `js/`: menu, theme, animation, lọc dự án, biểu mẫu
